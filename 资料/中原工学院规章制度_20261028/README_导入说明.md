# 中原工学院规章制度导入资料

采集日期：2026-10-28。共11份可导入TXT，来自中原工学院教务处、图书馆官网；同时保存8份PDF原件、3份正文网页HTML原件及8份PDF来源网页快照。

**这是官网公开可获取版本合集，尚未由学校确认全部制度的现行性。** 八份教务PDF均于2020-08-03印发、2020-09-01施行；部分网页在2022年发布，不表示文件于2022年修订。请在毕设展示中将本包说明为“官网公开制度知识库样本（保留版本与来源）”。

## 如何导入 CampusRAG

1. 解压资料包，打开“01_可导入TXT”。建议优先导入编号01—10，编号11是网页发布时间较早、实际修订时间不明的办事流程，可按需加入。
2. 在项目的知识库管理/文档上传页面逐份选择TXT文件，按下表选择现有分类。当前系统仅有学籍管理、奖惩办法、教务流程、宿舍管理等分类，图书馆资料可暂选教务流程。
3. 当前上传表单有“文档标题”和“规章分类”，没有独立版本栏。建议在标题末尾标注版本：教务文件加“2020年印发”，图书馆文明公约加“2026-02-26”，借阅规则加“网页更新2024-07”；证书流程加“修订时间不明”。具体文号、印发日期、网页日期、施行日期都保存在TXT头部，不要统一标为“最新版”。
4. 等待每份文档解析和索引完成后，使用“试问问题_无需导入.md”检查检索内容和引用。建议先用编号07测试缓考/补考/重修问题，再分批导入其他资料。
5. 同一制度只导入TXT或对应PDF其中一种，避免重复知识。ZIP、README、清单JSON、试问问题和HTML网页快照不需要导入；ZIP需要先解压。

TXT均为UTF-8编码，已核对无乱码和私有区公式字符；每份文件都在项目20MiB、30万字符、400分块的当前限制内。分块数量是依据现有解析器规则估算，尚未向应用上传。TXT不保留PDF物理页码，适合优先做文字检索；原件用于核对原始表格、版式和页码。

## 整理范围与核对说明

- **学籍、注册、预警、成绩、学分认定、考试纪律、缓补考与重修**：保留制度完整正文；去除印发通知、页码与重复印发落款。原件PDF完整保存。
- **绩点表格与公式**：已对照原图核对，转换为线性文本；只保留原文给出的分段范围，不自行推导逐分算法。两级制成绩的绩点对照表不能据此推断两级制一定纳入GPA，后续条款明确写的是百分制与五级制。
- **课程置换成绩转换表**：已按原表列序转写。原表“两级制：通过或合格”横跨90、80、70、60四列，没有给出唯一换算分；等级制B、B-、C+、C、C-同处50分列，忠实保留，未按常识改写。
- **课程考核管理办法**：TXT仅含第一至第四十条（PDF物理第2—11页）。第四十条后的附件目录及附件1—6保留在完整PDF中，不纳入TXT；其中考试纪律附件与编号08重复。第三十九条原文“自自”笔误予以保留。
- **图书馆规则**：2026文明公约使用其独立发布页全文；2024规章制度网页只摘取“图书借阅规则”一节，未把前面的旧文明公约再次导入。借阅规则中仍有阅览要求，与新公约重叠时请核实新公约与最新通知；保留原网页重复语句和编号。
- **证书丢失流程**：保留网页全文，但网页显示2014发布日期，实际修订时间不明。没有取得验证码保护的DOC附件；办理时间、材料和电话应以教务处现行通知核实。
- 每份TXT开头均有来源、日期、整理范围说明。它们是整理元数据，不属于学校条文。来源网页中的原始标点及可见笔误原则上保留。
- HTML原件仅保存页面源代码，未打包网站图片、样式及脚本依赖，离线显示可能与官网不同；正文仍已提取进TXT。
